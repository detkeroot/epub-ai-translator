# 📚 EPUB AI Translator (Mobile & Web)

**EPUB AI Translator** — автономное клиентское веб-приложение (Single Page Application) для интеллектуального перевода книг и ранобэ в форматах **EPUB** и **TXT** с помощью современных нейросетевых моделей (Google Gemini, OpenRouter, GLM-4).

Приложение спроектировано для работы непосредственно в браузере — как на **смартфонах (Android / iOS)**, так и на **десктопных компьютерах** — без необходимости развертывания бэкенд-серверов, установки Python, Node.js или контейнеров.

## 🌟 Ключевые возможности

- **100% Client-Side (Нулевой серверный оверхед):** Вся обработка файлов, распаковка архива книги, чанкинг текста, отправка запросов к AI и сборка готового EPUB происходят исключительно на стороне браузера пользователя.
- **Канонический адаптивный веб-интерфейс (v9.9.0 Web):**
  - Полноценные сфокусированные экраны по вкладкам: `Перевод`, `Валидатор`, `API Ключи`, `Настройки`, `Глоссарий`, `Промпт`, `Доктор`;
  - **Папки проектов (Project Folders):** автоматическое создание пронумерованных папок (`project_001`, `project_002`...) или выбор реальной папки на диске через File System Access API; в папку автоматически пишутся лог (`translation.log`), прогресс (`progress.json`), глоссарий (`glossary.json`) и готовая книга (`[Book]_translated.epub`), доступные для скачивания одним ZIP-архивом;
  - **Персистентный кэш глав (IndexedDB):** прогресс перевода сохраняется на устройстве; кнопка *«Продолжить с непереведённых»* позволяет переводить книгу частями, а в итоговый EPUB собираются **все** переведённые главы из всех сессий;
  - **Интеллектуальное ожидание кулдауна (Anti-Crash):** при 429 лимитах переводчик больше не падает, а автоматически ждёт разблокировки ключа и продолжает работу;
  - **Универсальный импорт глоссариев:** полная поддержка форматов из ПК-переводчика (поля `rus` и `note`, TXT с примечаниями `(note)`, `[note]`, `| note`);
  - **Screen WakeLock (Анти-сон):** экран смартфона не гаснет во время активного перевода;
  - **EPUB Доктор:** автоматический ремонт поврежденных EPUB-файлов (восстановление NCX, починка OPF-манифестов и битых сущностей XML);
  - **Диагностический экспорт:** кнопка *«Копировать лог»* формирует полный системный отчет (модель, ключи, ошибки) в один клик для быстрой отладки;
  - **Интерактивный Валидатор:** сплит-просмотр глав (оригинал vs перевод) с подсветкой пунктуации (тире, кавычки, запрещенные символы).
- **Продвинутый литературный промпт (Канон «Чтец Идей и Мастер Форм»):**
  - Встроенный специализированный промпт (более 300 строк выверенных инструкций издательского уровня);
  - **Принцип Альфа (Литературная цельность):** адаптация синтаксиса и ритма под нормы русского языка без потери смысла;
  - **Принцип Бета (Синтаксический стандарт):** строгое разграничение *Звука* (произнесенная речь оформляется через длинное тире `—`) и *Тишины* (мысли, цитаты, надписи оформляются в кавычки-«ёлочки» `«»`);
  - **Принцип Гамма (Техническая сохранность):** неприкосновенность каркасных XHTML-тегов, классов и служебных атрибутов.
- **Поддержка ведущих AI-провайдеров:**
  - **Google Gemini:** прямые вызовы REST API `generativelanguage.googleapis.com` (полная синхронизация с `translatorFork_MOD`: актуальная линейка **Gemini 3.8 Flash, 3.7 Flash, 3.6 Flash, 3.5 Flash-Lite, 3.5 Flash, 3.1 Flash-Lite, 3.1 Pro Preview, 3.0 Pro, 2.5 Pro, 2.5 Flash, Gemma 4 31B/26B** и нативная поддержка Thinking Config);
  - **DeepSeek API:** официальный эндпоинт `api.deepseek.com` (DeepSeek V4 Flash NonThink/Think, DeepSeek V4 Pro, deepseek-chat, deepseek-reasoner);
  - **OpenRouter:** доступ к бесплатному пулу (Gemini 2.0 Flash Exp, MiMo-V2-Flash, Qwen3 Coder 480B, DeepSeek V3.1 Nex, Chimera, GPT OSS 120B, GLM-4.5 Air, Gemma 3 27B) и топовым Claude 3.7 / 3.5 Sonnet, GPT-4o;
  - **Локальный API (OpenAI / Ollama):** поддержка любого локального OpenAI-совместимого эндпоинта (`http://127.0.0.1:11434/v1` или прокси) для работы с локальными моделями Qwen, DeepSeek, Llama;
  - **ZhipuAI (GLM-4):** поддержка моделей `glm-4-plus`, `glm-4-flash`, `glm-4.5-air` с клиентской генерацией JWT-токенов;
  - **Dry Run (Предпросмотр):** офлайн-просмотр готового сгенерированного промпта с подставленным чанком и терминами без отправки запроса и траты квот.
- **Интеллектуальный чанкинг и защита верстки:**
  - Автоматическое разбиение глав на смысловые фрагменты по тегам `<p>` и `<div>` без разрезания фраз;
  - Механизм **Restored Media**: если модель случайно удаляет `<img>` или иллюстрации, алгоритм автоматически восстанавливает потерянные медиа-теги в результирующем XHTML;
  - Очистка ответа от Markdown-артефактов (````xml...````, ````html...````) и валидация баланса тегов.
- **Динамический контекстный глоссарий:**
  - AI-генератор глоссария имен, сект, локаций и терминов по выбранным главам;
  - Динамическая фильтрация: в промпт чанка передаются только те термины, которые физически встречаются в текущем фрагменте;
  - Нечеткий поиск (Fuzzy Matching) и импорт/экспорт в JSON.
- **Пул API-ключей и контроль лимитов:**
  - Ротация нескольких API-ключей (по одному на строку);
  - Настройка RPM (запросов в минуту) и параллельных воркеров;
  - Учет сброса квот (ежесуточно по таймзоне Лос-Анджелеса для Gemini и скользящие 24 часа для других).
- **Локальное сохранение данных (localStorage):**
  - Ключи, пользовательские пресеты промптов, история переводов, глоссарий и статус сессии сохраняются локально на устройстве и не сбрасываются при перезагрузке страницы.

## 📁 Структура проекта

Проект декомпозирован на чистую модульную архитектуру исходного кода (`src/`) и систему сборки в один переносимый файл:

```text
epub-ai-translator/

├── index.html -> Ai...html     # Симлинк для веб-серверов
├── build.py                    # Скрипт сборки модулей в один HTML
├── .gitignore                  # Исключения Git (ключи, логи, кэш)
├── README.md                   # Настоящая документация
├── src/                        # Модульные исходники для разработки
│   ├── index.html              # Базовый HTML-каркас и разметка приложения
│   ├── css/
│   │   └── styles.css          # Стили оформления, темная тема и mobile-responsive
│   └── js/
│       ├── app.js              # Точка входа (инициализация приложения)
│       ├── config.js           # Конфигурация провайдеров, лимитов и дефолтных промптов
│       ├── lib/
│       │   ├── epub.js         # Парсер и упаковщик EPUB контейнера
│       │   └── jszip.min.js    # Локальная копия JSZip (для офлайн-сборки)
│       ├── utils/
│       │   ├── event-bus.js    # Шина событий (Pub/Sub)
│       │   ├── helpers.js      # Строковые утилиты, таймеры, форматирование
│       │   ├── language-tools.js # Детекция языков и CJK-сегментация
│       │   ├── text-processing.js # Чанкинг, балансировка тегов, защита картинок
│       │   ├── epub-tools.js   # Генерация OPF, NCX, NAV и метаданных

│       └── core/

│           ├── glossary-manager.js   # CRUD глоссария и динамическая инъекция
│           ├── task-manager.js       # Очередь задач и пул воркеров
│           ├── api-handlers.js       # Клиенты к Gemini, OpenRouter, GLM-4
│           └── translation-engine.js # Главный оркестратор конвейера перевода

    └── index_offline.html      # 100% офлайн-бандл (JSZip встроен прямо в файл)
```

## 🚀 Как запустить и пользоваться

### 1. На смартфоне (Android / iOS)

1. **Способ А (Самый простой — передача файла):**
   - Скопируйте файл `dist/index_offline.html` (или `Ai Translator.html`) на телефон (через Telegram «Избранное», LocalSend, провод или Google Drive).
   - Откройте файл в мобильном браузере:
     - На **Android**: рекомендуется **Kiwi Browser** или **Firefox Mobile** (они полноценно открывают локальные HTML-файлы с поддержкой локального хранилища и `fetch`). Также можно открыть в Chrome через `file:///...`.
     - На **iOS**: открыть через Safari или файловый менеджер (Documents by Readdle).

2. **Способ Б (Локальный хостинг в домашней сети):**
   - На компьютере в папке проекта запустите команду:
     ```bash
     python3 -m http.server 8080 --bind 0.0.0.0
     ```
   - На телефоне (подключенном к тому же Wi-Fi) откройте в браузере: `http://<IP_компьютера>:8080/dist/`
   - Нажмите в браузере **«Добавить на главный экран»** (Add to Home screen) — приложение будет открываться как нативная мобильная программа!

---

### 2. На компьютере

Просто откройте файл `dist/index.html` или `Ai Translator.html` двойным кликом в любимом браузере (Zen Browser, Chrome, Firefox, Safari).

## 🛠️ Разработка и сборка (`build.py`)

Если вы вносите правки в стили (`src/css/`) или логику скриптов (`src/js/`), не редактируйте монолитный 10 000-строчный HTML-файл вручную! Редактируйте файлы в папке `src/`, после чего соберите проект:

```bash
# Стандартная сборка (JSZip грузится из CDN)
./build.py

# Сборка 100% офлайн-версии (JSZip полностью встроен в HTML, сеть нужна только для API)
./build.py --offline

# Сборка в произвольный файл
./build.py --offline -o "Ai Translator.html"
```

Скрипт автоматически инлайнит CSS и все 16 JS-модулей в правильном порядке с сохранением комментариев-маркеров источника.

## 📱 Пошаговый процесс перевода книги

1. **Загрузка книги:** В панели `📁 Файл` перетащите или выберите `.epub` (или `.txt`) файл. Приложение автоматически прочитает оглавление и отобразит список глав.
2. **Выбор глав:** Отметьте нужные главы чекбоксами (или нажмите *«Выбрать все»*).
3. **Настройка API:** В панели `⚙️ Настройки`:
   - Выберите провайдера (например, *Google Gemini*);
   - Выберите модель (например, `Gemini 3.0 Flash Preview` или `Gemini 2.5 Flash`);
   - Вставьте один или несколько API-ключей в текстовое поле;
   - Задайте количество параллельных воркеров (для Gemini на бесплатных тарифах оптимально 1–2 воркера и RPM 5–10).
4. **Глоссарий (Опционально):** В панели `📋 Данные` -> вкладка `📖 Глоссарий` можно нажать *«✨ AI Генерация»*, чтобы нейросеть просканировала первые главы и составила начальный словарь имен и терминов.
5. **Запуск:** Нажмите кнопку `▶️ Начать перевод`.
6. **Контроль:** Следите за живыми логами во вкладке `📋 Логи` и шкалой прогресса.
7. **Скачивание:** По завершении перевода во вкладке `📥 Результаты` нажмите кнопку `📚 Скачать EPUB`. Приложение упакует переведенный текст обратно в корректный EPUB-файл с обновленными метаданными на русском языке.

## ⚠️ Инженерные нюансы и рекомендации

1. **Политика CORS на смартфонах:**
   - Google Gemini REST API (`generativelanguage.googleapis.com`) и OpenRouter нативно поддерживают CORS для клиентских браузерных запросов.
   - Однако при открытии страницы по протоколу `file:///` в обычном мобильном Google Chrome на некоторых версиях Android срабатывает защита `Origin: null`. Если вы сталкиваетесь с блокировкой сетевых запросов в Chrome, используйте **Firefox Mobile**, **Kiwi Browser**, либо запускайте приложение через локальный веб-сервер.
2. **Фоновый режим и энергосбережение на смартфонах:**
   - Мобильные операционные системы (Android / iOS) усыпляют вкладки браузера через 1–2 минуты после выключения экрана смартфона или переключения в другое приложение.
   - Во время объемного перевода рекомендуется **не блокировать экран** телефона либо отключить таймаут автовыключения экрана в настройках устройства.
3. **Безопасность API-ключей:**
   - Ключи хранятся исключительно в вашем локальном браузере (`localStorage`). Никакие данные не отправляются на сторонние серверы, кроме выбранного вами официального API-шлюза (Google, OpenRouter или ZhipuAI).
